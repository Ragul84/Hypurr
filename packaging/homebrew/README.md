# homebrew-hypurr

Homebrew tap for [Hypurr](https://github.com/Ragul84/Hypurr): message the coding agents on your computer as bots from iPhone, Mac, Linux or the terminal.

```sh
brew install --cask Ragul84/hypurr/hypurr      # Mac app (the host ships inside)
brew install Ragul84/hypurr/hypurr-host        # host only: Linux, headless Macs
```

Or without Homebrew: `curl -fsSL https://raw.githubusercontent.com/Ragul84/Hypurr/main/packaging/install.sh | sh`

Generated from [`packaging/homebrew`](https://github.com/Ragul84/Hypurr/tree/main/packaging/homebrew) by the release workflows in the Hypurr repo; edit the templates there, not this repo.
