# Hypurr brand

- `hypurr-icon.svg`: app icon (rounded square, standalone)
- `hypurr-glyph.svg`: the cat-with-purr-waves glyph on transparent (macOS Icon Composer layer)
- `hypurr-menubar.svg`: monochrome template mark for the macOS menu bar

Palette: violet `#A78BFA` → magenta `#F472B6` → cyan `#22D3EE` on deep indigo `#2A1065` → `#07102E`.
Raster icons (iOS/macOS app icons, menu bar, web favicon/touch icons, Linux SVG) are rendered from these files.
