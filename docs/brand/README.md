# Hypurr brand: Signal

- `hypurr-icon.svg`: app icon, the 9×9 dot cat in white on a black squircle
- `hypurr-glyph.svg`: the same mark at 64px
- `cat-dots.svg`: the dot cat on its own (ink on light)
- `icons/`: the Signal icon set (24 grid, 1.6 stroke, round caps), generated by `tools/signal-icons/icons.py`
- `fonts/`: licences for the bundled fonts, Inter and Doto (both SIL OFL 1.1)

Colours: ground `#EDEDEA`, card `#FFFFFF`, ink `#0E0E0E`, muted `#5C5C63`, and one red
`#D21F26` that always means "needs you". Dark: `#000000` / `#111111` / `#F5F5F2`, red text `#FF4D4F`.
No teal, no purple, no yellow/green.
